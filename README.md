# Grid Plan

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Marengo (YC S26) works in. Not affiliated with or endorsed by Marengo.

Planning sandbox for a fictional AI data-center campus. Every output is modeled from the visible assumptions (rack densities, tier multipliers, power factor) and labeled MODELED / ILLUSTRATIVE; nothing here is an engineering estimate. The campus schematic is not to scale.

Static export of a Next.js app. Built with Claude Code.
